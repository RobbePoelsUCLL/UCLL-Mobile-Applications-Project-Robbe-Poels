# Mobile App Project

## Getting started

1. Install project dependencies:

   ```bash
   npm install
   ```

2. Create a `.env` file:

   ```properties
   EXPO_PUBLIC_SUPABASE_URL = <supabase-url>
   EXPO_PUBLIC_SUPABASE_ANON_KEY = <supabase-pass>
   ```

3. Run the project:

   ```bash
   npx expo start
   ```
